# 방명록 만들기 (세미나용)

이름과 메시지를 저장하고 목록으로 보여주는 게시판을 3단계로 만들어 봅니다.

| 단계 | 브랜치 | 데이터 저장 위치 | 한계 |
|---|---|---|---|
| 1. 화면만 만들기 | `step1-ui` | 브라우저 메모리 (JS 배열) | 새로고침하면 사라짐 |
| 2. 서버 연결하기 | `step2-server` | 서버 메모리 | 서버를 재시작하면 사라짐 |
| 3. DB 연결하기 | `step3-db` | 데이터베이스 | — |

## 1단계: 화면만 만들기

### 실행 방법
`index.html` 파일을 브라우저로 열면 끝입니다. (더블클릭)

### 파일 구성
- `index.html` — 화면 구조 (입력 폼 + 목록)
- `style.css` — 디자인
- `script.js` — 저장 버튼 동작, 목록 그리기

### 발표 포인트
1. 이름/메시지를 입력하고 저장하면 목록에 바로 추가된다.
2. **새로고침(F5)을 하면 모두 사라진다.** → 데이터가 브라우저 메모리에만 있기 때문
3. 다른 사람(다른 브라우저)은 내 메시지를 볼 수 없다.
4. 그래서 다음 단계: 데이터를 **서버**에 보관하자!
